# Project 2 Response

For this project response, I explored three different interactive web projects that each approached interaction, design, and code in unique ways. What stood out to me most across all of them was how the projects used relatively simple interactions to create experiences that felt engaging, personal, and sometimes even uncomfortable. Each work demonstrated how code is not just functional, but also capable of shaping emotion, narrative, and participation.

## Projects

- https://xp30n.github.io/SAVE-THE-INTERNET/
- https://norahwilcox.github.io/CART263/projects/project-2/
- https://chloe-jpeg.github.io/CART263/project2/

## SAVE THE INTERNET

The project I found most surprising was **SAVE THE INTERNET**. The experience immediately felt loud, urgent, and chaotic in a way that matched the theme really well. The visuals, movement, and layered interface made it feel like I was inside an unstable version of the internet. What I found compelling was how overwhelming the project felt on purpose. It did not feel like a clean or traditional website; it felt messy, fast, and overstimulating, which made the concept stronger.

In terms of code, the project seems to rely heavily on JavaScript to control interaction, timing, and user response. The clicking, movement, pop-up style elements, and changing visuals create a sense that the page is constantly reacting to the user. The 3JS components also help push the project beyond a flat webpage by giving parts of the experience more depth and motion. The code supports the idea of the internet as something active, chaotic, and constantly shifting.

## Norah Wilcox Project

Norah Wilcox’s project felt more atmospheric and controlled. Compared to SAVE THE INTERNET, this piece invited slower exploration. The experience felt less about chaos and more about mood, space, and the user’s movement through the project. I found the pacing really effective because it gave the user time to observe and take in the environment.

The coding here felt more focused on creating a smooth interactive space. JavaScript seems to be used to guide transitions, control user input, and make the experience respond in a quiet but intentional way. The 3JS elements helped create a sense of depth and environment, making the project feel like a space the user enters rather than a page they scroll through. What stood out to me was that the code was not trying to overwhelm the viewer; instead, it created a more immersive and calm experience.

## Chloe JPEG Project

Chloe JPEG’s project stood out because of its playful visual identity and experimental interaction style. It felt like an interactive collage, where the user discovers the project by clicking, hovering, and exploring. The experience had a strong personality, and I liked how it encouraged curiosity rather than giving everything away immediately.

The code felt centered around interaction and surprise. JavaScript was used to make simple user actions feel more engaging, such as triggering movement, visual changes, or responses on the page. The 3JS elements added to the sense of play by giving the visuals more dimension and energy. Unlike Norah’s project, which felt smoother and more atmospheric, Chloe’s project felt more spontaneous and playful. The coding choices made the site feel alive and unpredictable, which matched the visual style well.
